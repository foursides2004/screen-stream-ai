# SFCC Sandbox and Development Concepts

## Sandbox

- Isolated development environment
- Separate from production
- Used for testing and development
- Has its own code version and configuration

## Code Versions

- Sandboxes have code versions
- Cartridges are associated with code versions
- Can have multiple code versions per realm

## Cartridge Path

- Defines which cartridges are loaded
- Order matters — first cartridge wins for conflicts
- Configured in Business Manager

## Content Assets

- Stored in SFCC content system
- Can be placed in slots
- Support rich text, HTML, and structured data
- Managed via Business Manager

## Slot Configuration

- Content slots hold content assets
- Can be assigned to categories or pages
- Support multiple content types:
  - Content Assets
  - Categories
  - Product Recommendations
  - HTML
  - Dynamic content

## Product Recommendations

- Engine-driven product suggestions
- Based on rules, co-occurrence, or collaborative filtering
- Can be placed in slots
- Configurable in Business Manager
